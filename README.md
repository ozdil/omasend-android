# 📱 omasend-android • Native Android Companion App for Omarchy

> **High-speed wireless file transfer, system share-sheet integration, and real-time clipboard bridge for Omarchy Linux.**

Author: **Ozan Özdil (ozdil)**  
License: **MIT**

---

## ✨ Features

- 📲 **System Share Sheet Integration:** Share photos, videos, or documents directly from Gallery, WhatsApp, or File Manager directly to your Omarchy Linux PC with 1 tap.
- 📋 **Live Clipboard Bridge:** Instantly copy your PC's clipboard text directly to Android, or send Android text to your Linux desktop clipboard with notifications.
- 🔒 **Zero-Trust Token Authentication:** Uses end-to-end cryptographic ephemeral token verification.
- ⚡ **Jetpack Compose UI:** Modern Dark AMOLED cyber-aesthetic user interface.

---

## 🛠️ Build & Install

```bash
# Clone repository
git clone https://github.com/ozdil/omasend-android.git
cd omasend-android

# Build Debug APK
./gradlew assembleDebug
```
